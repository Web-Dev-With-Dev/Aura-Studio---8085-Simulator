## ✨ KEY FEATURES & CAPABILITIES

- 💻 **Modern Syntax-Highlighted Assembly Editor**: Full-featured code editor with autocorrect, code formatting, directives, and error checking.
- ⚡ **Cycle-Accurate 8085 Simulation Engine**: Supports step-forward, step-backward, pause, reset, and continuous execution.
- 📺 **7-Segment LED Display Visualizer**: Supports Raw Bitmask, Direct BCD/Hex, and Multiplexed 4-digit / 8-digit displays.
- 🌊 **8-Bit ADC & DAC Waveform Oscilloscope**: Generates Sine, Sawtooth, Triangular, and Square waveforms with real-time graph telemetry.
- 🚦 **4-Way Traffic Light Controller Simulator**: Urban road intersection controller with North-South and East-West signals and pedestrian crossing indicators.
- 🌀 **Stepper Motor Motion Simulator**: Unipolar stepper motor simulator with Full-Step Clockwise/Counter-Clockwise and 8-step Half-Stepping microstepping.
- 📟 **16x2 Character LCD Display (HD44780)**: Full Hitachi HD44780 command set and DDRAM character rendering.
- 🗺️ **Memory Heatmap & Activity Visualizer**: Tracks code execution, memory reads, memory writes, and hotspot access loops across the 64 KB address space.
- 📊 **Multi-Format Register Inspector**: Real-time decoding of CPU registers in 5 formats simultaneously: Hex, Binary, Unsigned Decimal, Signed Decimal, and ASCII.
- ⏱️ **Delay Subroutine & Interrupt Wizards**: Automatic T-state calculations for exact timing delays and vector configuration.
- 📟 **Graphical 8085 Trainer Kit Emulator**: Keypad-and-display workflow replicating physical 8085 hardware trainer boards.
